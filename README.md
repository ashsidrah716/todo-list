# Todo List

A simple Todo List webpage built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using browser storage
- Interactive hover effects and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
